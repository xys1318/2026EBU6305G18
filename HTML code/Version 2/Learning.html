1. Color Vision & Fundamental Properties

The biological and physical basis of digital color encoding

Color is not an inherent property of objects—it is a perceptual response to visible light wavelengths (400–700 nm) detected by the human eye. The retina contains three types of cone cells sensitive to long (red), medium (green), and short (blue) wavelengths, forming the Tristimulus Theory of Color Vision.

  • Hue: Dominant wavelength, defines the color name (red, blue, green).
  • Saturation: Purity of a color; 100% = no white light mixture, 0% = grayscale.
  • Brightness/Value: Perceived light intensity emitted or reflected by a surface.
  • Metamers: Different light spectra that produce identical color perception—critical for encoding.

Color encoding translates human perception into numerical values that computers, screens, and printers can interpret and reproduce accurately.

2. RGB Additive Color Encoding

The universal standard for digital displays and screens

RGB is an additive model where Red, Green, and Blue light are combined to create all colors. It is the foundation of all digital display systems (monitors, phones, TVs).

  • Encoding format: (R, G, B) with 0–255 per channel (8-bit per channel, 24-bit total color depth).
  • (0, 0, 0) = Black; (255, 255, 255) = White; (255, 0, 0) = Pure Red.
  • Color depth: 8-bit = 16.7 million colors; 10-bit = 1.07 billion colors for professional use.
  • Grayscale conversion: L = 0.299R + 0.587G + 0.114B (standard luminance formula).

3. CMYK Subtractive Color Encoding

Industrial standard for printing and physical media

CMYK is a subtractive model used for printing, where inks absorb light instead of emitting it. Cyan, Magenta, and Yellow are the primary subtractive colors, and Black (Key/K) is added to produce true black.

  • Encoding logic: C = 1 - R, M = 1 - G, Y = 1 - B (in normalized values).
  • K channel: Eliminates muddy dark grays and saves ink in printing systems.
  • Used for: Books, posters, packaging, and all physical printed color media.
  • RGB→CMYK conversion requires gamut mapping for accurate color reproduction.

CMYK has a smaller color gamut than RGB—some bright digital colors cannot be printed accurately.

4. HSV Perceptual Color Encoding

Human-centered encoding for design and editing

HSV (Hue, Saturation, Value) is a perceptual model that matches how humans naturally select and adjust colors, widely used in design software (Photoshop, Figma).

  • Hue: 0°–360° on a color wheel (0°=red, 120°=green, 240°=blue).
  • Saturation: 0%–100% (color purity, 0% = grayscale).
  • Value: 0%–100% (brightness, 0% = black).
  • Intuitive for artists: Adjust hue for color, saturation for vibrancy, value for lightness.

5. YUV/YCbCr Encoding

Efficient encoding for image & video compression

YUV/YCbCr separates luminance (brightness) and chrominance (color) to enable efficient multimedia compression. Human eyes are far more sensitive to brightness than color, allowing chrominance data to be reduced.

  • Y: Luminance (brightness signal, full resolution).
  • U/Cb, V/Cr: Chrominance (color difference signals, reduced resolution).
  • YCbCr is the digital version used in JPEG, PNG, MPEG, and all video compression standards.
  • RGB→YCbCr conversion uses standardized matrix formulas for digital media.

YCbCr encoding is the reason image/video compression can reduce file size with minimal visible quality loss.

6. Advanced Color Encoding

Professional gamuts, high dynamic range & industry standards

Modern systems use extended color encoding for professional workflows, high dynamic range (HDR), and cross-device consistency.

  • CIE XYZ/CIELAB: Device-independent encoding for professional color management.
  • HDR Encoding: Rec. 2020 gamut & 10–12 bit depth for high-brightness displays.
  • Color Gamut: The range of colors a device can reproduce (sRGB, Adobe RGB, DCI-P3).
  • Metadata: Embedded encoding data to ensure consistent color across screens and printers.

Understanding advanced encoding is essential for multimedia production, UI/UX design, and professional media workflows.
