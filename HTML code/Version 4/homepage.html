Explore the Colour Spectrum

Hover over any swatch to instantly see its HEX, RGB, and CMYK values — the three colour encoding systems you'll master in our courses. Notice how the same colour translates differently across screen and print models.

/* — HEX (Web / CSS) ————————— */
red: #FF0000
orange: #FF6600
blue: #0066FF

/* — RGB (Screen / Additive) —— */
red: rgb(255, 0, 0)
orange: rgb(255, 102, 0)
blue: rgb(0, 102, 255)

/* — CMYK (Print / Subtractive) — */
red: cmyk(0%, 100%, 100%, 0%)
orange: cmyk(0%, 60%, 100%, 0%)
blue: cmyk(100%, 60%, 0%, 0%)
